# 呼吸灯逻辑与验证

- 上电默认全关。PB12 / MODE_SWICH 低电平按下，30 ms 消抖，每次按下只切换一次；长按不重复切换。三模式循环：全关 → 湿度流水呼吸 → 扩散呼吸 → 全关。
- 非 NFC 状态下，按键切换“全关 / 湿度流水呼吸 / 扩散呼吸”。NFC 期间忽略按键，结束后恢复此前模式。
- NFC 检测到射频场时，Q1～Q7 同步呼吸，周期 3 秒。每 40 ms 查询一次；允许 300 ms 短暂射频间歇或读失败，超时恢复背景模式。
- 湿度模式仅用 Q2～Q6，按顺序对应 0～16、16～32、32～48、48～64、64～80 %RH。已覆盖的段依次呼吸，末段按覆盖比例缩放亮度；单灯呼吸持续 1.2 秒，相邻灯延后 300 ms，整体每 3 秒重复。
- 湿度达到或超过 80 %RH 时，Q2～Q6 保持最高亮度。湿度为零或采样无效时不显示进度。Q1、Q7 在湿度模式始终关闭。
- Q1、Q2、Q7 的最大占空比是 80%，Q3～Q6 是 100%。Q0 始终关闭。
- 湿度模式每 2 秒启动一次 AHT20 采样，转换等待分散在主循环中；转换完成后检查忙状态和 CRC。

## 硬件对应

原理图：`SCH_Schematic3_2026-09-11.pdf`。Q1～Q7 指 74HC595 输出编号，不是原理图中同名 MOS 管编号。

SPI2：PA0 为时钟，PA4 为数据；PB14 为锁存；PA8 为低有效 OE。
74HC595 只有一个公共 OE，因此改由 TIM1 定时切换输出掩码，对每路单独调光。
每帧名义时长 4 ms，按亮度变化的时刻产生中断，每帧最多 8 次；实际波形包含短暂锁存消隐和中断延迟。

按键有外部上拉，PB12 配为输入。GPO 未接入 MCU，通过 ST25DV04K 用户 I2C 地址 0x53、EH_CTRL_Dyn（0x2002）bit 2 查询射频场，不改写 NDEF 或 NFC 配置。
寄存器依据：[ST25DV04K/16K/64K 官方数据手册](https://www.st.com/resource/en/datasheet/st25dv16k.pdf)。

HAL_Delay 在主线程等待期间继续查询 NFC，以覆盖墨水屏长时间刷新；中断上下文、I2C 忙或查询重入时跳过。
定时器负责输出，SysTick 负责动画和按键，均不调用阻塞式 HAL 通信函数。
`墨水屏项目.ioc` 已同步按键输入、PA8 输出、SPI2 速率和 TIM1 基础定时配置。外设运行逻辑由 `led_595.c` 管理。

## 2026-09-14 三模式扩展

扩散呼吸模式从 Q4 向两侧展开：Q4 → Q3/Q5 → Q2/Q6 → Q1/Q7，每组间隔 300 ms、每灯渐亮 600 ms；1500 ms 时全部亮起，保持 1 秒，再用 600 ms 同步渐暗熄灭，按 3100 ms 周期循环。绿色最高 80%，其他最高 100%。
安卓可通过经过认证的 BLE 接口直接选择三种模式、查询实际效果、时间进度和七路 duty。NFC 期间安卓选择的是背景模式，覆盖效果不中断。
